NodeWave post editor

    Open your current posts.json first, edit, then download and replace the file in the site folder. Work is also kept in this browser automatically.

    Import text

    Paste Markdown, HTML, or text copied from Word, Google Docs, a web page or Notion (formatting is kept: headings, bold, italic, links, lists, tables). You can also load a .md, .html or .txt file.
