About

NodeWave is a personal project by one person, published under the name Sputlab. I am building it because I want phones to be able to talk to each other when there is no network: in the mountains, during a blackout, or anywhere the signal is gone.

It started on 1 November 2026 with two phones and a single message, "CIAO - 73". Everything since then is in the changelog and the source code.

How AI is used

I use AI assistants (Claude, through Claude Code) to help write code, tests, documentation and the text of this website. I decide what gets built, I run it on real phones, I read and test what comes out of it, and I am responsible for what is published here. You can see it in the open: the commits made with that help say so in their message.

The tests on real hardware are mine and so are the mistakes. If something on this site or in the app is wrong, please tell me.

What to expect

  • It is pre-release software and it will have bugs.
  • The cryptography uses only the standard Android and Java libraries and has not been independently audited.
  • It is free software under the AGPL-3.0-or-later licence, with no ads and no tracking.
  • Money received and spent is listed on the transparency page.
