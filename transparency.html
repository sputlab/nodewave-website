How this is kept

  • The list is the file transparency.json in the website repository, so every change is public in the Git history.
  • Each donation received through PayPal is added, with the fee shown as an expense.
  • Expenses are only for the project: test phones, radio boards, hosting, domain and similar costs.
  • Questions or corrections: open an issue.
